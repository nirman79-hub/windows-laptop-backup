Privacy Policy

Windows Laptop Backup

This privacy policy explains how the Windows Laptop Backup application handles information when it is used to back up files from a Windows computer to the user's Google Drive account.

Information and Files

Windows Laptop Backup does not collect or store personal information on a separate application server. Files selected for backup remain under the user's control and are transferred directly from the user's Windows computer to the user's Google Drive account using rclone.

Google Drive Access

The application uses Google's OAuth authorization to access the user's Google Drive. Access is granted only after the user explicitly authorizes the application.

Google Drive access is used solely to perform the backup and file-management operations requested by the user.

Data Sharing

Windows Laptop Backup does not sell, rent, or share the user's files or personal information with third parties.

Data Storage

The application does not operate a server that stores copies of the user's backup files. Backup files are stored in the user's own Google Drive account.

OAuth Credentials

OAuth authorization information used by rclone is stored locally on the user's computer and is used to maintain authorized access to the user's Google Drive.

Revoking Access

The user can revoke the application's access to Google Drive at any time through their Google Account security settings.

Changes to This Policy

This privacy policy may be updated if the functionality or use of the application changes.
